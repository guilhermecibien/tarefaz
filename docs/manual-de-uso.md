# Manual de Uso do Tarefaz

## 1. Acesso ao sistema

A aplicação está disponível em:

https://tarefaz-production.up.railway.app/login

Ao abrir o endereço, o visitante visualiza a página de login. Para acessar o sistema, é necessário possuir uma conta.

## 2. Criar uma conta

1. Na página de login, selecione **Cadastre-se**.
2. Informe nome, e-mail e senha.
3. A senha deve possuir pelo menos oito caracteres e conter letras e números.
4. Se os dados forem válidos, o cadastro é realizado e o usuário é direcionado para o login.

## 3. Entrar na conta

1. Informe o e-mail e a senha cadastrados.
2. Selecione **Entrar**.
3. Após a autenticação, o sistema abre a lista pessoal de tarefas.

Cada conta visualiza somente as próprias tarefas.

## 4. Criar uma tarefa

1. No início da lista, localize o campo **Nova tarefa**.
2. Informe o título da atividade.
3. Opcionalmente, selecione uma data no campo de prazo ou utilize os atalhos **Hoje** e **Amanhã**.
4. Selecione **Adicionar**.

A tarefa é organizada automaticamente como atrasada, de hoje, próxima ou sem data.

## 5. Editar uma tarefa

1. Selecione **detalhes** ao lado da tarefa desejada.
2. Altere título, descrição, prazo ou a indicação **Importante**.
3. Selecione **Salvar**.

Também é possível clicar diretamente sobre o título de uma tarefa na lista para fazer uma edição rápida.

## 6. Usar o checklist

1. Abra os detalhes de uma tarefa ou selecione **+ checklist** na própria lista.
2. Digite o texto de uma etapa.
3. Selecione **Adicionar**.
4. Marque a caixa de seleção quando o item for concluído.
5. Caso necessário, utilize a opção de remover item.

O checklist permite dividir uma tarefa maior em pequenas etapas.

## 7. Concluir ou reabrir uma tarefa

- Para concluir, marque a caixa ao lado esquerdo da tarefa.
- A tarefa será exibida na seção **Concluídas**.
- Para reabrir, marque novamente a caixa da tarefa concluída.

## 8. Buscar tarefas

1. Localize o campo **Buscar**.
2. Digite uma palavra presente no título ou na descrição.
3. A lista exibirá somente as tarefas correspondentes.
4. Selecione **limpar** para remover a busca.

## 9. Alterar o tema

No canto superior da aplicação, selecione o botão **Escuro** ou **Claro**. A preferência de tema é mantida no navegador utilizado.

## 10. Gerenciar a conta

1. Selecione **Conta** no menu superior.
2. Para alterar nome ou e-mail, informe os novos dados e confirme com a senha atual.
3. Para alterar a senha, informe a senha atual, a nova senha e sua confirmação.

## 11. Sair do sistema

Selecione **Sair** no menu superior. A sessão será encerrada e o usuário retornará à tela de login.

## 12. Mensagens de validação

O Tarefaz apresenta mensagens quando algum dado está incorreto, por exemplo:

- Título de tarefa não informado.
- E-mail inválido.
- Senha fora das regras mínimas.
- Senha atual incorreta.
- Tentativa de cadastro com e-mail já utilizado.

# Roteiro do Vídeo Final

**Duração alvo:** 5 minutos  
**Objetivo:** apresentar o Tarefaz funcionando, os testes realizados e a melhoria aplicada após o feedback dos avaliadores.

## Preparação antes da gravação

Antes de iniciar, entre em uma conta de demonstração e deixe algumas tarefas prontas:

- Uma tarefa com prazo para hoje.
- Uma tarefa com prazo vencido.
- Uma tarefa sem prazo.
- Uma tarefa com checklist contendo pelo menos dois itens.

Dessa forma, será possível mostrar as seções da lista e a melhoria visual aplicada às tarefas urgentes.

## Roteiro

| Tempo | Tela e ação | Fala sugerida |
|---|---|---|
| 0:00 - 0:25 | Abra a tela de login. | “Olá, meu nome é Guilherme. Neste vídeo vou apresentar o Tarefaz, um sistema web para organizar tarefas pessoais de forma simples.” |
| 0:25 - 0:50 | Mostre cadastro ou faça login. | “O sistema permite criar uma conta e acessar uma lista pessoal de tarefas. Cada usuário visualiza apenas as próprias informações.” |
| 0:50 - 1:30 | Mostre a página principal e crie uma tarefa. Defina um prazo. | “Na tela inicial, posso adicionar uma tarefa informando apenas o título. O prazo é opcional e também existem atalhos para hoje e amanhã.” |
| 1:30 - 2:00 | Mostre as seções Atrasadas, Hoje, Próximas, Sem data e Concluídas. | “As tarefas são organizadas automaticamente de acordo com o prazo. Isso facilita visualizar o que está atrasado, o que precisa ser feito hoje e o que pode ser realizado depois.” |
| 2:00 - 2:35 | Abra detalhes de uma tarefa. Edite descrição, prazo ou marque como importante. | “Ao abrir os detalhes, posso editar as informações, adicionar uma descrição, mudar o prazo e marcar a tarefa como importante.” |
| 2:35 - 3:10 | Demonstre o checklist. Marque um item como concluído. | “Também é possível adicionar um checklist. Isso ajuda a dividir uma tarefa maior em pequenas etapas e acompanhar o que já foi realizado.” |
| 3:10 - 3:35 | Use a busca e conclua uma tarefa. | “A busca localiza tarefas pelo título ou descrição. Para concluir uma atividade, basta marcar a caixa ao lado da tarefa. Ela passa para a seção de concluídas e pode ser reaberta se necessário.” |
| 3:35 - 3:55 | Mostre tema escuro e página Conta. | “O sistema possui tema claro e escuro. Na página Conta, o usuário pode alterar nome, e-mail e senha, sempre confirmando a senha atual.” |
| 3:55 - 4:30 | Mostre tarefas de hoje e atrasadas. | “Cinco pessoas testaram o sistema. Uma das sugestões foi destacar melhor tarefas urgentes. A partir desse feedback, apliquei cores leves e uma borda lateral nas tarefas de hoje e atrasadas para facilitar a identificação das prioridades.” |
| 4:30 - 4:50 | Mostre rapidamente GitHub ou README. | “O código, os documentos, os diagramas e os testes automatizados estão organizados no repositório GitHub do projeto.” |
| 4:50 - 5:00 | Retorne à lista principal. | “Esse foi o Tarefaz. Obrigado.” |

## Pontos importantes

- Grave a tela em resolução legível e mantenha o cursor visível.
- Fale com naturalidade; não é necessário ler cada frase de forma literal.
- Mostre somente funcionalidades que estejam funcionando na versão publicada.
- Mantenha o vídeo próximo de cinco minutos, pois o material da disciplina apresenta instruções conflitantes sobre duração mínima e máxima.
